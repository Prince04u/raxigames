Raxiwin — Static website package

Deploy: drop this folder into Cloudflare Pages, Vercel, or Netlify as a static site.
All pages are single-file HTML with inlined CSS and JSON-LD. No build step required.

Files:
- index.html, about.html, features.html, gaming-experience.html, community.html,
  trust-security.html, responsible-gaming.html, faq.html, blog.html, contact.html,
  privacy-policy.html, terms.html, sitemap.html
- blog-*.html (six articles)
- sitemap.xml, robots.txt
- assets/logo.svg, assets/favicon.svg, assets/app-icon.svg
